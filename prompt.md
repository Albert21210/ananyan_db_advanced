Помоги выполнить задание по продвинутым базам данных.

Необходимо организовать перенос ресурсов из MSSQL в новую OLAP-базу PostgreSQL по четырём направлениям:
- Анализ закупок продукции.
- Анализ продаж товаров.
- Анализ работы персонала.
- Анализ остатков.

Нужно подготовить три скрипта:

1. SQL-скрипт для создания структуры OLAP-базы данных в PostgreSQL.
2. SQL-запросы для выборки необходимых ресурсов из MSSQL.
3. PL/pgSQL-скрипт для вставки данных в PostgreSQL.

Также необходимо создать отдельный скрипт для формирования ресурса «Время». Таблица должна содержать код, дату начала месяца, дату окончания месяца, название месяца, год, номер квартала и название квартала.

Раздели код на четыре SQL-файла. Проверь корректность запросов, соответствие требованиям задания и правильность переноса данных. Если обнаружишь ошибки, исправь их.
